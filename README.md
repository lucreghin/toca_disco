Sobre o Projeto: Toca Disco é um programa que toca músicas a partir de um catálogo autoral meu. O usuário escolhe qual 
    música quer ouvir e dá uma nota de 0 a 10 para elas. Depois escolhe se quer ouvir outra música ou encerrar o programa.
Tecnologias Utilizadas: Python 3, pygame, ANSI 
Como usar: Certifique-se de ter python 3 instalado em seu computador. Baixe os arquivos mp3 disponíveis e toca-disco.py.
    Digite py toca-disco.py ou python toca-disco.py no terminal
O que pratiquei no projeto: variáveis, condicionais (if, elif e else), entrada de dados, controle de audio no pygame,
    loops (while), personalização do terminal (ANSI) e organização de código.
